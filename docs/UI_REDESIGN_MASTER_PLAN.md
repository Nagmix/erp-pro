# خطة إعادة تصميم ERP Pro الشاملة (Vibrant SaaS)

## الهدف
تحويل واجهة النظام بالكامل إلى تجربة بصرية حديثة وأنيقة ومتسقة عبر جميع الشاشات، مع معالجة عيوب RTL/LTR وحقول الإدخال والقوائم المنسدلة، وتنفيذ ذلك على مراحل صغيرة واضحة وقابلة للقياس.

## النطاق المعتمد
- إعادة تصميم الألوان، الهوامش، المسافات، الحواف، الظلال، الأيقونات، وحالات التركيز/الأخطاء.
- توحيد تجربة النماذج والجداول والتنقل على مستوى النظام.
- إصلاح مشاكل اتجاه النص في الحقول والقوائم المنسدلة.
- تطبيق تدريجي حسب الأولوية مع فحص جودة بعد كل مرحلة.

## الأساس الحالي
- نظام الثيم العام في `src/app/globals.css`.
- المكونات الأساسية: `input`، `select`، `button`، `data-table`، `erp-field`.
- كثافة شاشات عالية (120+ صفحة) لذلك التنفيذ سيكون على دفعات.

## المبادئ التصميمية الجديدة (Vibrant SaaS)
- ألوان حيوية متوازنة للوضع الفاتح والداكن.
- مقياس مسافات موحد (8px base).
- لغة أيقونات موحدة.
- حقول إدخال ونماذج بحالات ثابتة (focus/error/disabled).
- RTL افتراضي مع LTR للحالات التقنية فقط (أرقام/تواريخ/أكواد).
- قابلية وصول أفضل (تباين وتركيز بصري واضح).

## مراحل التنفيذ

### المرحلة 1: Design Foundation
- توحيد Design Tokens في `globals.css`.
- تعريف الطبقات الدلالية: `surface`, `surface-muted`, `brand`, `success`, `warning`, `danger`, `info`.
- توحيد قواعد المسافات والحواف والظلال.

### المرحلة 2: Core UI Components Refactor
- تحديث `button`, `input`, `select`, `textarea`, `dropdown`, `dialog`, `card`, `table`, `badge`.
- توحيد الارتفاعات والحواف وحدود التركيز.
- تحسين حالة الأخطاء والحقول المطلوبة عبر `ErpField`.

### المرحلة 3: RTL/LTR Stability Pass
- اعتماد RTL افتراضي للنصوص العربية.
- قصر LTR على الأرقام/الأكواد/البريد/الهاتف/التواريخ.
- ضبط تموضع الأيقونات داخل Select وCombobox.
- إزالة تعارضات `text-left` و`text-right`.

### المرحلة 4: Navigation & Layout Redesign
- صقل الهيدر والسايدبار والشريط السياقي.
- توحيد هيكل الصفحة (header/actions/KPI/content).
- تحسين الاستجابة للأجهزة المختلفة.

### المرحلة 5: Forms UX Deep Fix
- إعادة تنظيم النماذج الطويلة في المحاسبة والموارد البشرية والمبيعات والمشتريات.
- تحسين التسلسل البصري للحقول والرسائل.
- تقليل التزاحم داخل dialogs.

### المرحلة 6: Data Tables Modernization
- تعميم نمط موحد مستمد من `src/components/erp/data-table.tsx`.
- تحسين رؤوس الجداول والكثافة والفلاتر.
- ضبط محاذاة النصوص والأرقام بما يناسب RTL.

### المرحلة 7: Screen-by-Screen Rollout
- دفعة 1: Dashboard + Sales + Purchases.
- دفعة 2: Accounting + Inventory.
- دفعة 3: HR + CRM.
- دفعة 4: Reports + Settings + Operations.

### المرحلة 8: Iconography & Micro-Interactions
- توحيد أحجام الأيقونات وسماكتها.
- تحسين hover/active/focus transitions.
- توحيد نمط الإشعارات والتنبيهات.

### المرحلة 9: QA, Lint, Visual Audit
- تدقيق RTL، النماذج، القوائم، التباين.
- إصلاح أي regressions بعد كل دفعة.
- تتبع منجزات قبل/بعد داخل هذا الملف المرجعي.

## آلية التنفيذ
- تنفيذ كل مرحلة بشكل مستقل ثم مراجعتها.
- عدم الانتقال للمرحلة التالية قبل إغلاق checklist الجودة.
- تسليم دفعات شاشات قابلة للاستخدام الفعلي.

## تعريف الاكتمال النهائي
- مظهر موحد وعصري في كل الوحدات.
- اختفاء مشاكل اتجاه النص وشكل المدخلات والقوائم.
- اتساق كامل في المسافات والألوان والأيقونات.
