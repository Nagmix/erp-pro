# سجل التغييرات - مشروع ERP Pro

## الإصدار 0.2.0 (2026-04-30)

### الإنجازات الرئيسية

#### المرحلة 0: إصلاح الأساسيات (إنجاز جزئي ~60%)
- **حماية المسارات**: إنشاء `proxy.ts` كبوابة حماية لجميع المسارات المحمية، يتضمن:
  - التحقق من `erp_session` cookie في كل طلب
  - إعادة توجيه غير المصادقين إلى `/login` مع حفظ المسار الأصلي
  - فك تشفير رمز الجلسة والتحقق من انتهاء الصلاحية
  - استثناء المسارات العامة (login, api, static files)

- **نظام المصادقة**: إنشاء نظام مصادقة تجريبي شامل:
  - صفحة تسجيل دخول احترافية بتصميم RTL مع خط Cairo
  - أزرار دخول تجريبي سريع لكل دور
  - دعم 4 أدوار: مدير النظام (admin)، المحاسب (accountant)، مدير المبيعات (sales)، مدير الموارد البشرية (hr)
  - نسيان كلمة المرور (واجهة + API)
  - تخزين مزدوج للجلسة (localStorage + cookie)
  - API تسجيل دخول وخروج والتحقق من الهوية

- **الهيكل الأساسي**: إنشاء المكونات الأساسية:
  - `AppSidebar` - شريط جانبي مع تنقل بين الوحدات (10 وحدات)
  - `AppHeader` - شريط علوي مع بحث شامل ومستخدم
  - `DataTable` - جدول بيانات متقدم مع فرز وفلترة
  - `KpiCard` - بطاقات مؤشرات الأداء مع رسوم بيانية مصغرة
  - `DocForm` - نموذج مستند عام
  - `DynamicRowTable` - جدول صفوف ديناميكي (للفواتير والقيود)
  - `StatusBadge` - شارات الحالة بألوان مختلفة
  - `GlobalSearch` - بحث شامل عبر جميع الوحدات
  - `ExportButton` - تصدير البيانات (CSV, Excel, PDF)
  - `ErrorBoundary` / `PageSkeleton` - معالجة الأخطاء والتحميل

#### المرحلة 1: البنية التحتية (إنجاز جزئي ~30%)
- **API Routes**: إنشاء طبقة API شاملة:
  - `/api/auth/login` - تسجيل دخول تجريبي مع إعداد cookie
  - `/api/auth/logout` - تسجيل خروج مع مسح الجلسة
  - `/api/auth/me` - التحقق من الجلسة الحالية
  - `/api/auth/forgot-password` - نسيان كلمة المرور
  - `/api/data/[doctype]` - CRUD عام (GET: قائمة، POST: إنشاء)
  - `/api/data/[doctype]/[name]` - عمليات على مستند واحد (GET, PUT, DELETE)
  - `/api/data/[doctype]/bulk` - عمليات جماعية
  - `/api/dashboard/kpis` - مؤشرات لوحة التحكم
  - `/api/reports/[reportName]` - التقارير
  - `/api/method/[...path]` - وكيل لطرق ERPNext المخصصة

- **طبقة البيانات**: إنشاء أساس React Query:
  - `api.ts` - عميل API مع معالجة أخطاء شاملة
  - `hooks.ts` - React Query hooks (useDocList, useDoc)
  - `query-client.ts` - إعدادات Query Client مع إعادة المحاولة

- **اتصال ERPNext**: إنشاء `backend.ts` للاتصال بخادم ERPNext (إعداد أساسي)

- **الأنواع والمساعدات**:
  - `types.ts` - تعريفات الأنواع الأساسية للمستندات والمستخدمين
  - `helpers.ts` - دوال مساعدة (تنسيق التاريخ، العملة، الأرقام)
  - `utils.ts` - أدوات عامة (cn، formatCurrency)

### المشاكل المعروفة

1. ~~**أخطاء TypeScript**~~ — **مُحدَّث (M-21):** `ignoreBuildErrors: false`؛ راجع [`system_fixes_tracker.md`](./system_fixes_tracker.md). قد تبقى تحسينات نوعية عرضية.
2. **نظام المصادقة**: يستخدم Base64 بدلاً من JWT (غير آمن للإنتاج)
3. **بيانات تجريبية**: معظم الصفحات تعرض بيانات ثابتة (hardcoded) بدون اتصال حقيقي بـ ERPNext
4. **صفحات قائمة فقط**: أغلب الصفحات تعرض قوائم بدون نماذج إنشاء/تعديل كاملة
5. **مشكلة تسجيل الدخول**: في بيئة البروكسي (Caddy) قد لا تعمل ملفات تعريف الارتباط بشكل صحيح
6. **لا توجد اختبارات**: لا يوجد أي اختبارات وحدة أو تكامل
7. **تكرار في الكود**: دوال مكررة مثل formatCurrency و cn في ملفات مختلفة
8. **أيقونة خارجية**: رابط أيقونة من z-cdn.chatglm.cn يجب استبداله بأيقونة محلية
