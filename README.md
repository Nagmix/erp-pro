## المعمارية

```
┌─────────────────┐     ┌──────────────────────┐     ┌──────────────────────┐
│   المتصفح       │     │   خادم Next.js       │     │   خادم ERPNext       │
│   (RTL/Arabic)  │────→│   (Frontend + API)   │────→│   (Backend)          │
│                 │     │   Port: 3000         │     │   Port: 8000         │
│  - React 19    │←────│   - SSR / CSR        │←────│   - REST API         │
│  - Zustand     │     │   - API Routes       │     │   - MariaDB          │
│  - React Query │     │   - proxy.ts         │     │   - Redis            │
└─────────────────┘     └──────────────────────┘     └──────────────────────┘
```

## المميزات

- **واجهة عربية أصيلة**: دعم RTL كامل مع خط Cairo العربي
- **مصادقة متعددة الأدوار**: مدير النظام، المحاسب، مدير المبيعات، مدير الموارد البشرية
- **57 صفحة لوحة تحكم**: تغطي جميع وحدات الأعمال
- **مكونات قابلة لإعادة الاستخدام**: 60+ مكون UI مخصص
- **طبقة API شاملة**: CRUD عام، مصادقة، تقارير، وكيل ERPNext
- **Docker Compose**: نشر متكامل بنقرة واحدة
- **مفتوح المصدر**: حر في الاستخدام والتعديل

## التشغيل

### المتطلبات
- Node.js 20+ أو Bun
- npm أو bun أو pnpm

### التطوير المحلي (وضع تجريبي)

```bash
# تثبيت التبعيات
npm install

# تشغيل وضع التطوير
npm run dev

# أو بناء وتشغيل الإنتاج
npm run build
npm start
```

### Docker Compose (الإنتاج مع ERPNext)

```bash
# إعداد أول مرة
./erp-pro.sh setup

# تشغيل
./erp-pro.sh start

# إيقاف
./erp-pro.sh stop
```

## هيكل المشروع

```
src/
├── app/                    # صفحات Next.js App Router
│   ├── login/              # صفحة تسجيل الدخول
│   ├── api/                # مسارات API (11 مسار)
│   └── (dashboard)/        # صفحات لوحة التحكم (57 صفحة)
├── components/
│   ├── erp/                # مكونات ERP مخصصة (10)
│   └── ui/                 # مكونات shadcn/ui (50)
├── lib/
│   ├── client/             # أدوات العميل (API, Hooks, Query)
│   ├── server/             # أدوات الخادم (ERPNext Backend)
│   └── core/               # أنواع ومساعدات
├── stores/                 # مخازن Zustand (Auth)
├── hooks/                  # Hooks مخصصة
└── proxy.ts                # Middleware حماية المسارات
```
